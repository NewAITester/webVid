# نمونه‌های «🧩 وارد کردن کد ویدیو»

در پنجرهٔ «📜 موشن‌اسکریپت» دکمهٔ «🧩 وارد کردن کد ویدیو (JS/HTML/Python)» را بزنید و یکی از این فایل‌ها را انتخاب کنید:

| فایل | نوع | چه چیزی خوانده می‌شود |
|---|---|---|
| `moviepy_titles.py` | MoviePy | سه صحنه (ColorClip + TextClip)، محو شدن، تصویر متحرک (جایگزین)، فایل صدا |
| `manim_intro.py` | Manim | دو کلاس Scene، Write / Create / FadeIn / Transform / Rotate / Indicate |
| `manim_graph.py` | Manim | محورها، نمودار تابع (لایهٔ کد)، نقطه‌ها، LaggedStart، فرمول |
| `../scenes.js` | Canvas 2D | ۸ صحنه، ۶۱ مقدار قابل‌تغییر، موسیقی ساخته‌شده با کد |
| `../build.py` + `../template.html` + `../scenes.js` | چند فایل | قالب با فایل‌های همراه پر می‌شود (همان کار build.py) |

مقدارهای بالای فایل پایتون (`TITLE = "…"  # توضیح`) و متن‌های داخل کد قابل‌تغییرند؛
با «⬇ کد اصلیِ تغییریافته» همان فایل پایتون/JS با مقدارهای تازه ذخیره می‌شود.
