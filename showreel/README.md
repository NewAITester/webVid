# Motion Reel — شوریل ۱۵ ثانیه‌ای موشن‌گرافی با کد

- `showreel.html` — **کد کامل تک‌فایلی**. در مرورگر باز کنید و «▶ پخش با صدا» را بزنید (فاصله = پخش/توقف، نوار = جلو و عقب، ⬇ WAV = ذخیرهٔ موسیقی).
  موسیقی هم با کد (WebAudio) ساخته می‌شود؛ هیچ فایل جانبی لازم نیست.
- `scenes.js` — هشت صحنه، گذارها و موسیقی (۱۲۸ ضرب در دقیقه، ۸ میزان).
- `../src/engine/reelfx.js` — قطعه‌های موشن (گرداب ذرات، انفجار ضربی، دگردیسی شکل، بیست‌وجهی سیمی، وارپ ستاره، زمین نئونی، اکولایزر حلقه‌ای، نوشتهٔ ذره‌ای، کلمهٔ کوبنده، گذار، گلیچ). همین فایل داخل برنامه هم استفاده می‌شود.
- `build.py` — ساخت `showreel.html` از روی دو فایل بالا.
- `make_template.mjs` — ساخت پروژهٔ آمادهٔ برنامه (`public/templates/motion-reel.lyricstudio.json`).
