# Motion Reel — شوریل ۱۵ ثانیه‌ای موشن‌گرافی با کد

- `showreel.html` — **کد کامل تک‌فایلی**. در مرورگر باز کنید و «▶ پخش با صدا» را بزنید (فاصله = پخش/توقف، نوار = جلو و عقب، ⬇ WAV = ذخیرهٔ موسیقی).
  موسیقی هم با کد (WebAudio) ساخته می‌شود؛ هیچ فایل جانبی لازم نیست.
- `scenes.js` — هشت صحنه، گذارها و موسیقی (۱۲۸ ضرب در دقیقه، ۸ میزان).
- `../src/engine/reelfx.js` — قطعه‌های موشن (گرداب ذرات، انفجار ضربی، دگردیسی شکل، بیست‌وجهی سیمی، وارپ ستاره، زمین نئونی، اکولایزر حلقه‌ای، نوشتهٔ ذره‌ای، کلمهٔ کوبنده، گذار، گلیچ). همین فایل داخل برنامه هم استفاده می‌شود.
- `build.py` — ساخت `showreel.html` از روی دو فایل بالا.
- `make_template.mjs` — ساخت پروژهٔ آمادهٔ برنامه (`public/templates/motion-reel.lyricstudio.json`).

## موشن‌اسکریپت: همین شوریل، داخل برنامه و قابل ویرایش

فایل `reel.motion.js` همین شوریل است به زبان «موشن‌اسکریپت» برنامه. برنامه این کد را می‌خواند و از هر خط یک لایه می‌سازد. بعد از آن هر چیزی را می‌شود دستی تغییر داد یا با المان دیگری عوض کرد.

1. در ویرایشگر: **لایه‌ها ← 📜 موشن‌اسکریپت** (یا «＋ افزودن ← کد و اسکریپت»).
2. از «نمونه‌ها…» گزینهٔ «شوریل موشن ۱۵ ثانیه» را بزنید یا این فایل را با «📂 باز کردن فایل» باز کنید.
3. **▶ اجرا و ساخت لایه‌ها**. فهرست صحنه‌ها و المان‌ها پایین پنجره می‌آید. روی هر المان بزنید تا لایه‌اش باز شود.
4. در زبانهٔ «✎ تنظیم» هر المان: تنظیم‌های نام‌دار (تعداد ذره، سرعت، نوشته…)، رنگ‌های کی‌فریم‌پذیر و **⇄ تعویض با** المان دیگر.
5. **📤 از لایه‌ها**: از لایه‌های فعلی (با همهٔ تغییرهای دستی) دوباره کد می‌سازد. **↶ برگرداندن** اجرای آخر را لغو می‌کند.

بهترین نتیجه وقتی است که اسکریپت روی پروژهٔ نمونهٔ «🎬 شوریل موشن» (آهنگ ۱۲۸ ضرب) اجرا شود، چون المان‌ها با ضرب‌های آهنگ می‌تپند.

راهنمای کوتاه زبان:

```js
tempo(128)                                   // beats(n) و bars(n) از روی این حساب می‌شوند
scene('نام', bars(1),                        // صحنه‌ها پشت سر هم می‌آیند
  bg('#07070C'),                             // یا bg(['#123', '#000']) برای گرادیان
  vortex({ n: 1300, c1: '#E4142A' }),        // المان آماده با تنظیم‌هایش
  text('سلام', { size: 200, enter: ['pop', 0.4], from: beats(1) }),
  shape('ring', { w: 400, h: 400, strokeW: 8, keys: { sc: [[0, 0.5], [0.4, 1, 'outBack']] } }),
  code(function (ctx, e) { e.circle(0, 0, 50 + e.kick * 40, e.c1) }))
transition('wipe')                           // wipe | flash | glitch | iris روی مرز صحنه‌ها
overlay(adjust({ fx: [['grain', { amt: 12 }]] }))   // روی کل ویدیو
```

المان‌ها: vortex, burst, starfield, swarmText, slamText, morph, wire, grid3d, eqRing, shock, dotGrid, marquee, hud, wipe, flash, glitch, iris.

در لایه‌های «کد آزاد»، هر خطی به شکل `const نام = مقدار; // برچسب [کمینه..بیشینه]` خودکار یک اسلایدر، انتخاب رنگ یا جعبهٔ متن در زبانهٔ «✎ تنظیم» می‌سازد.
